## Data folder

- `demo.csv` is a tiny dataset included only so you can test that the code runs.
- For the coursework, you will be evaluated on unseen datasets.
- Do **not** commit large datasets into the repository.

Tip: keep your own datasets outside the repo (or add them to `.gitignore`).

- Datasets I used:
    - example_dataset.csv
    - Sales.csv (from email from Raza)
    - WineQuality.csv (from email from Raza)
    - Smartphone_Use.csv (https://www.kaggle.com/datasets/jimarahman/smartphone-usage-and-addiction-analysis-dataset?resource=download)
    - most_viewed_videos.csv (https://www.kaggle.com/datasets/mubashirsidiki/most-watched-yt-videos-rankings-2026)
    - songs.csv (https://www.kaggle.com/datasets/moonknightmarvel/dataset-of-songs-with-genreartistmovielanguage)
    - world_happiness.cvs (https://www.kaggle.com/datasets/obaidhere/world-happiness-report)
